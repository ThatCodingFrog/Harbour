# What is this?
This is a library + launcher for PC ports of old console games.  Its purpose is similar to Steam to make it easier for gamers to set up and play games such as [Ship of Harkinian](https://www.github.com/HarbourMasters/Shipwright), [2Ship](https://www.github.com/HarbourMasters/2ship2harkinian), [Dusklight](https://www.github.com/TwilitRealm/Dusklight), and more. It also could support mods that would be too complex to merge upstream.  It supports automatic update checking for each port, easy setup, and more!

# How do I set it up?
All you have to do is download the executable for your operating system. From there, you can automatically download, update, and launch your favorite PC ports.

# I have a game I want to suggest, where should I do that?
Go check out [ThatCodingFrog/harbour-manifest](https://www.github.com/ThatCodingFrog/harbour-manifest) -- it's the hub for the library data that Harbour Ports reads from
